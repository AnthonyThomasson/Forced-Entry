# Pointer

Side file of `domain-general` (`SKILL.md`).

`Pointer` (`pointer.gd`, `class_name`, static; interface 26) is the one place a screen point and a world point are converted. Each method takes a node of the world and reads that node's viewport: `world_of(node, screen)`, `screen_of(node, world)`, `screen_transform(node)` (world to screen), `visible_world_rect(node)`, `screen_mouse(node)` and `world_mouse(node)`. In 2D it is the viewport's canvas transform (the active `Camera2D`'s view; the identity with no camera or viewport), so a world in a second viewport converts by its own view. In the 3D render mode (#193) the rig binds itself (`bind_3d`) and a node of the viewport the sim's `Camera2D` serves converts through the orthographic camera: a screen point is the ray that meets the ground plane `y = 0`, and `screen_transform` is the camera's exact ground-to-screen affine at its yaw, pitch and zoom, built from the camera's own transform and size through the DISPLAYED rect of the 3D view (never the picture's internal size). `is_3d(node)`, `world_vector(node, v)` and `world_direction(node, dir)` give a screen step or direction as the ground one (untouched outside 3D): screen-relative WASD, the spectator's pan and the camera's look-ahead read them; a seated driver's keys do not.

- `inject(screen)` stands a screen point in for the mouse until `release()`: `screen_mouse` and `world_mouse` (what feeds the player's aim, the camera's look-ahead and the command menu's non-mouse fallback) return it. It never warps the real mouse (the command server's `aim` does that, through `Pointer.screen_of`), and an input event keeps its own position. `TestWorld.restore` releases it (`domain-testing`).

- 3D tests: `pointer_3d_ground_ray_test.gd` (yaw 0, 45, 120 at 0 and 216 internal lines, hand-worked), `pointer_3d_aim_and_space_test.gd` and `ui/inspector_selects_under_mouse_3d_test.gd` (the aim, Space's nearest-to-mouse and the inspector at hand-worked screen points), `move_screen_relative_test.gd` (WASD at yaw 90, the driver's raw keys), `camera_screen_relative_test.gd` (pan and look-ahead), `camera_rig_turns_on_held_keys_test.gd` (Q / E). `tests/_general/rig_probe.gd` puts a test world in 3D.

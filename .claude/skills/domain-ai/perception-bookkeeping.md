# AI · Perception · Shared bookkeeping (#192)

Work the perceptions share instead of repeating, each with a test that holds the answer to the plain path and counts the fast path.

- **Contacts in one pass** (`perception_contacts.gd`, `agent_hostility.gd`). `contacts.known()` reads the hostile verdicts once (`hostility.reasons(memory)`, newest wins) and the flashed ids once, not once per sighting. `hostility.bulk_reads` counts it. `tests/ai/perception/known_matches_per_sighting_test.gd` holds `known()` to the per-sighting rule over verdict changes, flashes, expiry and a freed character.
- **One character list** (`perception_sight.gd`). `sight.others()` gathers the group `characters` once per physics frame and world root for every perception (a static; `list_builds` counts gatherings) and filters it per NPC, skipping freed nodes. A character spawned after the gather is first seen the next frame.
- **House intake** (`perception_house.gd`, `take_in`). It repeats set-up only when it changed: rooms and openings by array identity (`doorways.set_house`), the carried grenades when an item in either grenade slot is a different object (`learn_carried`), posture heights once (`learn_body`). `intake_reads` counts each. A caller that changes a rooms array in place must pass a new array. `tests/ai/perception_cadence_suite.gd`.
- **Early event filter** (`goal_controller.gd` `_on_event`). A `hit` beyond both `combat.hit_awareness_radius` and `senses.hearing_radius` that is not on this NPC, and a `callout` beyond `radio.callout_range` (when above 0), are dropped on arrival. `hearing.process_hit` and `process_callout` ignore exactly those, so what an NPC knows is unchanged: keep the two in step. `tests/ai/perception/early_hit_filter_matches_late_test.gd` hands each case to the late classifier too.
